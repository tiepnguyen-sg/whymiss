# Repository structure

Mirror this exactly. Every directory has one job. If a file does not obviously
belong in exactly one place, the design is wrong — stop and reconsider before
inventing a new directory.

## Structural rules worth internalising

**`internal/domain` and `internal/rca` are pure.** Together they are the product.
Everything else is plumbing that feeds them or renders their output. This is why
`depguard` guards them and why they are the only packages with a hard import
allowlist. If you find yourself wanting to import an HTTP client into `rca`, the
design has gone wrong — the data should have been in the `Timeline`.

**`internal/source` is a quarantine zone.** All client-specific knowledge lives
there and converts to `domain` types at the boundary. The test of a correct design:
adding Teku should touch `internal/source/` and one line of `registry.go`, nothing
else. `make check.isolation` enforces this by grepping for client names outside that
directory.

**`internal/app` is the only wiring point.** Every other package receives its
dependencies through its constructor and knows nothing about how the program is
assembled. This is what makes the whole thing testable without a running node.

**`test/corpus` is not test scaffolding — it is an asset.** It is your regression
suite, your accuracy benchmark, and the most persuasive artifact in a grant
application. Treat corpus scenarios with the same review rigour as production code.

**`docs/adr` is written before the code it justifies.** An ADR written afterwards is
a rationalisation, not a decision record. When an agent proposes a dependency or an
architectural change, the ADR is the first deliverable.

## Initialise

```bash
git init
go mod init github.com/<your-org>/whymiss

# Replace the module-path placeholder in the bundled config
grep -rl 'CHANGEME' . | xargs sed -i 's|CHANGEME|<your-org>|g'

lefthook install
golangci-lint config verify
make help
```

Then start the first session with:

> Read `docs/BUILD_PROMPT.md` and `docs/causes.md`. Sections 1–8 of BUILD_PROMPT
> are LAW. We are executing Phase 1, task 1.1.
